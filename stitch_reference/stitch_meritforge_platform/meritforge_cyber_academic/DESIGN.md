## Brand & Style

This design system merges institutional academic rigor with high-stakes cyberpunk fintech. Designed for an intense evaluation environment like the Smart India Hackathon, it projects extreme meritocratic transparency, high cryptographic trust, and sovereign student agency. It balances cutting-edge web3-inspired gamification with institutional grade seriousness.

The aesthetic philosophy is **Tactile Cyber-Minimalism with Luminous Accents**. It relies on deep cosmic slate and obsidian backgrounds to command focus, punctuated by sharp, high-intensity neon conduits: electric cyan for computational proof and dynamic XP metrics, deep royal violet for system architecture and jury arbitration, and rich amber gold for sovereign wealth, escrow verification, and top-percentile academic rank. Visual elements prioritize information density, rapid scannability, glass-etched precision, and crisp tactile micro-feedback.

## Colors

The palette leverages a deep obsidian slate canvas (`#07071A`) to ensure zero eye fatigue during marathon judging sessions, while making chromatic status signals immediately unmistakable.

- **Primary Cyan (`#00F0FF`)**: Denotes computational integrity, real-time telemetry, active focus states, and the MANA XP token mechanism.
- **Secondary Violet (`#7C3AED`)**: Rooted in academic royalty and institutional authority; powers administrative controls, jury governance, and high-order category structures.
- **Tertiary Gold (`#F59E0B`)**: Represents audited capital, ZENI tokens, escrow locks, top-tier leaderboard standings, and verified hackathon credentials.
- **Neutral Layers (`#07071A` to `#171A42`)**: Form an architectural stepped-dark surface system, preventing pitch-black clipping and offering tactile depth for dense grids.

Every luminous accent must maintain an intentional functional role: Cyan tracks personal student kinetic progress; Gold represents real value and external audit validation; Violet governs permissions and fast-pass arbitration.

## Typography

The typographic hierarchy establishes a crystal-clear distinction between narrative academic prestige and granular computational proof.

- **Headlines (`Plus Jakarta Sans`)**: Built with geometric authority, wide apertures, and tight tracking. They present institutional milestones, jury project headers, and team designations with crisp confidence.
- **Body (`DM Sans`)**: Chosen for high-efficiency reading across dense candidate dossiers, jury rubric rubrics, and project problem statements.
- **Technical & Token Metrics (`JetBrains Mono`)**: Deployed across dual-token balances, smart contract escrow states, timestamps, leaderboard rankings, and system telemetry tags. Tabular figures are enforced for all numerical fields to eliminate jitter during real-time value updates.

## Layout & Spacing

The layout is built on a responsive 12-column fluid grid system optimized for high-density academic dashboards and live hackathon judging stages.

- **Desktop (1280px+)**: 12 columns with `1.5rem` gutters and dynamic margins up to a max-width container of `1440px`. Accommodates side-by-side split panels: left telemetry/evaluation criteria and right live project execution/repository sandbox.
- **Tablet (768px - 1279px)**: 8 columns with `1rem` gutters. Peripheral token counters and sidebar navigation collapse into compact horizontal rail docks.
- **Mobile (< 768px)**: 4 columns with `0.75rem` gutters and `1rem` edge margin. Token counters compress into an overhead persistent pill HUD; multi-column stats collapse into single-column progressive disclosure accordions.

Internal component gaps follow strict 4px/8px multiples. Data tables and matrix cards maintain compact internal padding (`space-sm` to `space-md`) to ensure maximum visible data density without visual friction.

## Elevation & Depth

Depth is conveyed through **etched glassmorphic stratification and cold photonic luminescence** rather than standard muddy drop shadows.

1. **Canvas Level (Ground)**: Deep matte obsidian (`#07071A`) textured with an imperceptible 1-pixel hairline coordinate grid for technical grounding.
2. **Structural Panels (Level 1)**: Slate-navy surface (`#0B0C24`) backed with an ultra-subtle border outline (`rgba(255, 255, 255, 0.07)`). Zero shadow blur; clean separation is achieved purely through value contrast.
3. **Floating Modules & Escrow Cards (Level 2)**: Translucent glass (`rgba(17, 19, 51, 0.75)`) with `backdrop-filter: blur(16px)` and a top-edge 1px highlight mimicking directional overhead rim lighting.
4. **Interactive Hover & Modal Focus (Level 3)**: Surfaces elevate with focused, directional colored glow conduits. Escrows project a subtle amber rim radiance (`rgba(245, 158, 11, 0.2)` blur 20px), while active MANA progression cards emit cyan luminescence (`rgba(0, 240, 255, 0.22)` blur 24px).
5. **Jury Fast-Pass & Urgent Alerts**: Layered over an intense blurred backdrop with a crisp dual-tone perimeter line (`#7C3AED` bleeding into `#00F0FF`).

## Shapes

The design system embraces a **precise, aerospace-inspired structural silhouette** using Roundedness Level `1` (Soft - base 4px/0.25rem). 

- Standard interactive controls, token chips, and matrix cells utilize a controlled `4px` radius to reflect technical discipline.
- Main dashboard cards and modal sheets scale to `8px` (`rounded-lg`).
- Continuous circular pills (`9999px`) are strictly reserved for volatile runtime states: live hackathon time-remaining timers, dual-token pill meters, and online jury connection beacons.
- Hard geometric chamfers or razor-cut corner accents (1px hairline tick marks) can be applied to top-tier institutional badges and contract verification stamp cards.

## Components

### Buttons
- **Primary Cyber-Action (Cyan)**: Solid `#00F0FF` background, obsidian `#07071A` bold text. On hover: subtle scale micro-lift with `box-shadow: 0 0 16px rgba(0, 240, 255, 0.45)`.
- **Institutional Governance (Violet)**: Deep violet base (`#7C3AED`) with clean white text; used for submitting final hackathon rubrics, smart contract deployments, and verified jury signatures.
- **Secondary Ghost**: Translucent glass (`rgba(255, 255, 255, 0.04)`), 1px border (`rgba(255, 255, 255, 0.15)`), active text in cyan or white.

### Dual-Token HUD & Chips
- **MANA XP Chip**: Dark cyan tint (`rgba(0, 240, 255, 0.08)`) with cyan border, displaying an electric cyan spark icon followed by bold mono-spaced XP numerical tallies.
- **ZENI Currency Chip**: Deep amber tint (`rgba(245, 158, 11, 0.08)`) with amber border, featuring the sovereign gold coin glyph and audited balance.
- **Status Tags**: Uppercase monospaced micro-labels with a 6px breathing status dot (green for "ESCROW LOCKED", cyan for "UNDER REVIEW", violet for "JURY DELIBERATION").

### High-Density Data & Escrow Cards
- Built using `#111333` with an etched hairline border.
- Escrow cards feature a dedicated top sub-header: release milestone conditions, multi-sig counterparty indicators, and real-time locked ZENI amounts.
- Metric cards showcase small uppercase mono labels at the top with oversized tabular values below, supplemented by mini sparkline activity bars.

### Jury Fast-Pass & Role-Switching Banner
- Persistent or dockable header banner featuring an electrified violet-to-cyan gradient hairline border.
- Includes an instant physical-style toggle switch that immediately switches permissions, viewports, and action schemas between "Student Contributor" and "Official Hackathon Jury".
- Fast-pass queue highlights priority evaluations with a rhythmic amber pulse indicator.

### Input Fields & Controls
- Form inputs feature dark sunken wells (`#07071A`) with subtle inward outlines. Focusing an input engages an immediate neon cyan hairline perimeter and glowing coordinate caret.
- Checkboxes and radio selectors maintain square and circular technical geometries with high-contrast cyan center fill-points when engaged.
